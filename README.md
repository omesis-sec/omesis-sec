**[Square + WhatsApp Order Automation](https://github.com/omesis-sec/square-whatsapp-order-automation)**

What it shows: REST APIs and webhooks, signature verification, idempotent event handling, a D1 (SQLite) data layer, automated tests, and a human-handoff support inbox.
